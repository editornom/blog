## Notes from a non-developer, for non-developers

This is **Non-Dev Notes** (비개발노트).

I am not a developer. I kept getting stuck trying to build things with AI. Stuck because I didn't know what a terminal was. Stuck because I couldn't read an error message. Stuck because I had no idea how to show anyone the thing I had finally managed to make.

The problem was not that answers were missing. Answers are everywhere — but **they are all written for people who already know.** To understand "just move it to an environment variable," you need to know what an environment variable is. Search for that, and you hit another word you don't know.

So I write down what I find out each time I get stuck, in the order I needed it. So that someone like me can follow along from the very beginning.

## House rules

- **Order matters.** Environment variables never come before the terminal. Every post links to what you should read first.
- **No unexplained words.** When a technical term appears for the first time, it gets explained right there.
- **Every code example is actually run.** If you copy something and it doesn't work, a beginner assumes they did something wrong. So all examples are executed before publishing. Deliberately broken examples are labeled as such.
- **No dangerous commands.** Anything that could wreck your machine if pasted straight into a terminal gets filtered out.

## What's covered

Working with AI coding tools, the environment you need (terminal, git, editors), the minimum programming concepts required to read what AI hands you, how the web actually works, how to put what you built in front of other people, and enough general IT literacy to follow a conversation.

This is not a place to become an expert. It is a place to **stop getting stuck**.
