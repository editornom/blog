이 글은 AI를 활용해 코드를 작성하는 '바이브코딩' 시 기대할 수 있는 결과와 주의할 점을 안내합니다. 겉보기에는 그럴듯하지만 실제로는 동작하지 않거나 수정하기 어려운 코드를 만났을 때, 문제를 해결하는 데 필요한 관점을 제시합니다.

## 바이브코딩이란

AI에게 '이렇게 만들어달라'는 대략적인 지시만으로 코드를 요청하는 것을 **바이브코딩(vibe coding)**이라고 합니다. 예를 들어, "근사한 웹사이트를 만들어줘"와 같은 지시가 대표적입니다. 이때 AI에 내리는 지시를 **프롬프트(prompt)**라고 합니다. 즉, AI에 프롬프트를 입력하여 코드를 생성하는 것이 바이브코딩의 기본 방식입니다.

이는 전문가에게 상세한 설계도 없이 "근사한 집 한 채 지어달라"고만 말하는 것과 유사합니다. AI는 프롬프트에 담긴 요청을 가장 짧은 경로로 달성하려 합니다. 덕분에 빠르게 결과물을 얻을 수 있는 것처럼 보입니다.

## AI 생성 코드의 특징

AI가 빠르게 생성한 코드가 항상 좋은 것은 아닙니다. AI는 완벽한 코드를 생성하지 않습니다. 오히려 당면한 문제를 해결하기 위해 최단 경로를 택하는 경향이 있습니다.

예를 들어, AI는 기존 코드를 더 깔끔하게 정리하는 **리팩토링(refactoring)**을 스스로 수행하지 않습니다. 전체 **코드베이스(codebase; 프로젝트의 모든 코드 파일)**를 탐색하여 중복된 부분을 찾아 제거하거나, 더 나은 구조로 변경하는 데 적극적이지 않습니다. 이는 제한된 정보 안에서만 판단하고, 전체적인 그림을 고려하지 않는 주니어 개발자와 유사합니다.

또한, AI가 작성하는 테스트 코드는 중요한 예외 상황(프로그램 실행 중 예상치 못한 문제)을 놓치거나 불필요하게 중복될 수 있습니다. 코드 품질이나 설계 표준을 주관적으로 평가하여 개선하지도 않습니다. 이로 인해 유사한 기능의 코드가 여러 파일에 분산되거나 오류 처리가 미흡하여 유지보수가 어려운 코드가 축적될 수 있습니다.

AI에 모든 것을 맡기면 코드를 고치기가 점점 더 어려워질 수 있습니다. 초반에는 편리하게 느껴지더라도, 결국 더 많은 시간과 노력이 필요하게 될 수 있습니다.

## AI와 효과적으로 협업하는 방법

AI를 단순히 '마법'처럼 여기고 모든 것을 맡기는 대신, 능숙한 시니어 아키텍트처럼 AI를 다루고 주니어 개발자처럼 구체적으로 지시해야 합니다. AI가 스스로 아키텍처를 결정하도록 두기보다, 원하는 기술 스택과 구조를 먼저 정하고 AI에 명확히 지시하는 것이 중요합니다.

프롬프트의 품질이 코드 품질을 좌우한다는 점을 기억해야 합니다. 단순히 "블로그를 만들어줘"라고 요청하기보다, "Next.js 15와 Tailwind CSS를 사용해서 헤드리스 아키텍처의 블로그를 만들어줘"와 같이 상세한 제약 조건을 명시해야 합니다. 또한, '시스템 프롬프트'처럼 AI의 역할을 정의하고 코드 작성 규칙을 미리 설정하면 훨씬 체계적인 결과물을 얻을 수 있습니다.

AI가 생성한 코드를 무조건 신뢰하기보다, 직접 검토하고 필요한 경우 설정을 확인하여 수정해야 합니다. AI는 코드를 작성하지만, 궁극적인 책임은 사용자에게 있습니다. 문제가 발생했을 때 'AI가 만들었으니 정확할 것'이라고 생각하기보다, 스스로 디버깅하고 해결하려는 자세가 필요합니다.

## 바이브코딩의 활용 가능성과 한계

바이브코딩은 아이디어를 빠르게 프로토타입(시제품)으로 만들거나, 특정 기능을 신속하게 구현하는 데 매우 유용합니다. 새로운 아이디어를 검증하거나 간단한 자동화 스크립트, 개인 학습용 프로젝트 등을 만드는 데 큰 도움이 됩니다.

하지만 바이브코딩만으로 장기적으로 유지보수하기 좋고 안전하며 확장 가능한 복잡한 애플리케이션을 만들기는 어렵습니다. 프로덕션 환경(실제 사용자들이 사용하는 서비스)에서 안정적으로 운영될 고품질 코드를 AI가 '알아서' 생성할 것이라고 기대해서는 안 됩니다. AI는 주니어 개발자와 같으므로, 명확한 지시와 지속적인 검토 없이는 원하는 결과물을 얻기 어렵습니다.

### 바이브코딩 시 흔한 실수

- 구체적인 지시 없이 AI에 모든 것을 맡기는 경우.
- AI가 생성한 코드를 검토 없이 바로 사용하는 경우.
- AI 생성 코드의 오류를 'AI 결과물이므로 정확하다'고 판단하는 경우.
- 전체 코드 구조를 고려하지 않고 단편적인 기능만 요청하는 경우.

### 효과적인 바이브코딩을 위한 질문

AI에게 '나만의 간단한 웹사이트를 만들어달라'고 요청하는 상황을 가정해 보세요. 단순히 최종 결과물만 말하는 것이 아니라, 어떤 기능이 필요한지, 어떤 기술을 사용할지, 어떤 구조로 만들지 등 AI에 어떤 지시를 내려야 깔끔하고 오래 사용할 수 있는 결과물을 얻을 수 있을지 스스로에게 질문하고 답해 보십시오.
