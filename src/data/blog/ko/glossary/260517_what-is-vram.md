# VRAM이란?

### 사전적 정의 (Dictionary Definition)
VRAM(Video Random Access Memory)은 그래픽 처리 장치(GPU)에서 이미지 렌더링 및 연산 데이터를 처리하기 위해 사용되는 전용 고속 메모리입니다. 현대 인공지능 생태계에서는 모델의 가중치와 연산 데이터를 적재하는 핵심 물리 자원으로 활용되며, AI 모델의 규모와 구동 환경을 결정하는 결정적인 요소가 됩니다.

### 실무 사용 예시 (Practical Use Case)
소형 언어 모델(SLM)을 도입하면 VRAM 점유율이 낮아져 일반 사용자용 PC나 모바일 기기에서도 AI 서비스를 직접 구동할 수 있는 온디바이스 환경을 구축하기 용이합니다.
