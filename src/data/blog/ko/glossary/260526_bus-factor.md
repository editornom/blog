# 버스 지수(Bus Factor)이란?

### 사전적 정의 (Dictionary Definition)
버스 지수(Bus Factor)는 특정 프로젝트나 조직에서 지식과 역량이 소수의 인원에게 얼마나 집중되어 있는지를 나타내는 지표입니다. 이는 "프로젝트의 운영이 중단되지 않으려면 최소 몇 명의 팀원이 갑작스럽게 이탈(예: 버스에 치임)해야 하는가"를 묻는 개념적 수치입니다. 지수가 낮을수록(예: 1) 특정 개인에 대한 의존도가 높아 리스크가 큼을 의미하며, 지수가 높을수록 지식 공유가 잘 이루어져 팀의 회복 탄력성이 높음을 나타냅니다.

### 실무 사용 예시 (Practical Use Case)
러스트(Rust)와 같이 가파른 학습 곡선을 가진 기술을 도입할 경우, 해당 언어에 숙련된 극소수의 개발자만이 코드를 이해하고 관리할 수 있는 상황이 발생하기 쉽습니다. 이 경우 버스 지수는 1에 수렴하게 되며, 해당 개발자의 부재 시 프로젝트 전체가 중단될 위험이 커집니다. 따라서 기술 리더는 코드 리뷰와 문서화, 지속적인 교육을 통해 지식 파편화를 막고 버스 지수를 높여 경영 리스크를 관리해야 합니다.
