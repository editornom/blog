# 테스트 타임 컴퓨팅이란?

### 사전적 정의 (Dictionary Definition)
테스트 타임 컴퓨팅(Test-time Computing)은 인공지능 모델이 학습(Training) 과정이 아닌, 실제 사용자 질문에 응답을 생성하는 추론(Inference) 단계에서 추가적인 연산 자원을 투입하여 성능을 극대화하는 기술적 방법론입니다. 이는 모델의 크기나 학습 데이터의 양을 늘려 지능을 높이던 기존의 '스케일링 법칙(Scaling Laws)'이 자본 및 데이터 효율성 측면에서 한계에 도달함에 따라 등장한 새로운 패러다임입니다. 추론 시 모델이 결과물을 즉시 내놓는 대신, 여러 경로로 사고를 전개하거나 자가 검증 과정을 거치게 함으로써 복잡한 논리적 추론이나 문제 해결 능력을 향상시키는 것이 핵심입니다.

### 실무 사용 예시 (Practical Use Case)
논리적 고도화가 필요한 수학적 정리 증명이나 복잡한 소프트웨어 아키텍처 설계 단계에서 활용됩니다. 모델이 한 번의 연산으로 답변을 출력하는 대신, '생각의 사슬(Chain of Thought)' 기법 등을 통해 중간 추론 단계를 여러 번 반복하고 스스로 오류를 수정하도록 유도하여 답변의 신뢰도를 높이는 데 사용됩니다.

### 관련 단어 (Related Words)

- 생각의 사슬 (Chain of Thought)
