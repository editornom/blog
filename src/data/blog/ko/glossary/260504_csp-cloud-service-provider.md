# CSP이란?

**사전적 정의 (Dictionary Definition)**
클라우드 서비스 제공업체(Cloud Service Provider, CSP)는 인터넷 네트워크를 통해 서버, 스토리지, 데이터베이스, 네트워크 등 가상화된 컴퓨팅 리소스를 온디맨드(On-demand) 형태로 제공하는 기업을 의미합니다. 사용자는 물리적 인프라를 직접 소유하거나 관리할 필요 없이 CSP가 구축한 자원을 임대하여 사용하며, 사용한 만큼 비용을 지불하는 종량제 모델을 따릅니다. 대표적인 제공업체로는 아마존 웹 서비스(AWS), 마이크로소프트 애저(Azure), 구글 클라우드 플랫폼(GCP) 등이 있습니다.

**실무 사용 예시 (Practical Use Case)**
기업은 특정 CSP에 대한 기술적 종속(Vendor Lock-in) 현상을 방지하고 서비스 가용성을 극대화하기 위해, 복수의 CSP를 선정하여 인프라를 분산 배치하는 멀티 클라우드 전략을 채택합니다.

**관련 단어 (Related Words)**

* 벤더 종속 (Vendor Lock-in)
* 클라우드 보안 (Cloud Security)
