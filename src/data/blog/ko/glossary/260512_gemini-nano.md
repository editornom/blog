# 제미나이 나노 (Gemini Nano)란?

### 사전적 정의 (Dictionary Definition)
구글이 개발한 거대 언어 모델(LLM) '제미나이(Gemini)' 제품군 중 가장 크기가 작고 효율적인 온디바이스 최적화 인공지능 모델입니다. 모바일 기기(모바일 AP)나 PC의 하드웨어(CPU, GPU, NPU) 사양에 맞추어 탑재할 수 있도록 설계되었으며, 저전력 고성능 구조로 오프라인 상태에서도 강력한 자연어 처리와 텍스트 분석, 스마트 답장, 문장 자동 교정 연산을 로컬 장치 자체에서 수행하도록 지원합니다.

### 실무 사용 예시 (Practical Use Case)
구글 픽셀(Pixel) 스마트폰 내에서 녹음된 목소리를 즉석에서 텍스트로 녹취 및 요약하거나, 구글 크롬(Google Chrome) 브라우저에서 '글쓰기 도우미(Help me write)', '스마트 탭 그룹 생성', 'AI 방문 기록 검색' 기능을 수행할 때 클라우드 서버에 내 개인 텍스트 데이터를 단 한 글자도 업로드하지 않고 내 컴퓨터 내부에서 안전하고 즉각적으로 연산하는 로컬 샌드박스 엔진으로 활용됩니다.
