# L7이란?

### 사전적 정의 (Dictionary Definition)
L7은 OSI(Open Systems Interconnection) 7계층 모델의 최상위 계층인 응용 계층(Application Layer)을 의미합니다. 사용자가 네트워크 응용 프로그램과 상호작용할 수 있도록 지원하며, HTTP, HTTPS, DNS, FTP, SMTP 등 서비스의 목적에 부합하는 고수준 프로토콜이 이 계층에서 작동합니다. 네트워크 관리 및 보안 측면에서는 단순한 IP 주소나 포트 번호를 넘어 패킷 내부의 실제 데이터(Payload)를 식별하여 트래픽을 제어하거나 분석하는 기술적 단위를 뜻합니다.

### 실무 사용 예시 (Practical Use Case)
eBPF 기술을 활용한 클라우드 네이티브 관측성 도구에서는 커널 수준에서 L7 프로토콜 데이터를 가로채어 분석함으로써, 별도의 코드 수정 없이도 마이크로서비스 간의 HTTP 호출 성공률이나 응답 지연 시간을 실시간으로 모니터링하는 데 사용됩니다.

### 관련 단어 (Related Words)
