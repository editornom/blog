# 什么是秀尔算法？

### 词典定义 (Dictionary Definition)
秀尔算法（Shor's Algorithm）是由彼得·秀尔（Peter Shor）于 1994 年设计的一种量子算法。它是一种数值分析技术，能够比经典计算机以压倒性的速度解决大整数的质因数分解问题。经典算法在进行质因数分解时需要消耗指数时间（Exponential time），而秀尔算法可以在多项式时间（Polynomial time）内完成运算，这被视为计算复杂性理论的一个重大转折点。

### 实际应用案例 (Practical Use Case)
秀尔算法被视为证明现代公钥密码体系 (PKI) 基石——RSA 算法以及基于离散对数问题的椭圆曲线密码 (ECC) 脆弱性的核心依据。它表明，一旦大规模量子计算机成为现实，当前的数字安全体系可能会被瓦解。因此，在安全实务和研究领域，秀尔算法被用作开发和标准化能够抵御此类攻击的后量子密码 (PQC) 技术的基准点。
