# 什么是 NoSQL？

## 词典定义 (Dictionary Definition)
NoSQL 是 'Not Only SQL' 的缩写，是为克服传统关系型数据库管理系统 (RDBMS) 的严格模式（Schema）和水平扩展限制而设计的非关系型数据库系统的统称。它不使用固定的表结构，而是采用键值对 (Key-Value)、文档 (Document)、图形 (Graph) 等灵活的数据模型来处理结构化和非结构化数据。这在大规模分布式环境中提供了高可用性和扩展性，满足了现代架构中比起数据一致性更看重性能和灵活性的需求。

## 实务应用案例 (Practical Use Case)
NoSQL 主要应用于实时产生海量非结构化数据的社交媒体动态处理、物联网 (IoT) 传感器数据采集、大规模日志分析系统，以及数据模式频繁变更的初期服务开发环境。

## 相关词汇 (Related Words)
- RDBMS
- 水平扩展 (Horizontal Scaling)
- 无模式 (Schema-less)
