# 什么是 L7？

### 词典定义 (Dictionary Definition)
L7 指的是 OSI（开放系统互连）七层模型中的最高层——应用层 (Application Layer)。它支持用户与网络应用程序进行交互，HTTP、HTTPS、DNS、FTP、SMTP 等符合服务目的的高级协议均运行在这一层。在网络管理和安全方面，它超越了简单的 IP 地址或端口号，指的是通过识别数据包内部的实际数据 (Payload) 来控制或分析流量的技术单元。

### 实际应用案例 (Practical Use Case)
在利用 eBPF 技术的云原生可观测性工具中，通过在内核层面拦截并分析 L7 协议数据，可以在无需修改代码的情况下，实时监控微服务间的 HTTP 调用成功率或响应延迟。

### 相关词汇 (Related Words)
