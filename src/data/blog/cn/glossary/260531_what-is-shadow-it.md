## 什么是影子 IT？

### 词典定义 (Dictionary Definition)
影子 IT (Shadow IT) 是指在组织内部，未经 IT 部门正式批准或管理，由个别部门或员工自行引入并使用的信息技术系统、软件、应用程序及服务。这通常是为了避开复杂的审批程序并立即提高工作效率，随着 Cloud 计算和 SaaS 的普及，这种情况变得更加严重。由于其存在于组织的中央控制之外，它成为了导致安全漏洞暴露、数据泄露风险、成本管理不透明等治理层面问题的主要原因。

### 实际应用案例 (Practical Use Case)
当企业的 Cloud 治理自动化政策过于严格，导致资源创建和部署延迟时，开发团队为了维持生产力，绕过正式程序，使用个人支付方式在外部公共 Cloud 实例上创建并进行项目的案例。

### 相关术语 (Related Words)
- Cloud 治理 (Cloud Governance)
- 治理债务 (Governance Debt)
- 自动化的悖论 (Automation Paradox)
