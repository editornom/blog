# 什么是 AGPL？

### 词典定义 (Dictionary Definition)
AGPL (GNU Affero General Public License) 是由自由软件基金会 (FSF) 发布的一种强开源 (Copyleft) 许可证。传统的 GPL 许可证仅在物理分发软件时才会产生源代码公开义务，这导致许多公司利用所谓的“ASP 漏洞 (ASP Loophole)”，即通过网络服务 (SaaS) 形式运行代码而无需公开源代码。AGPL 的设计初衷正是为了解决这一问题。如果对应用了 AGPL 许可证的软件进行修改，并以此通过网络提供远程服务，用户则有义务公开该修改版本的源代码。

### 实际应用案例 (Practical Use Case)
诸如终端工具 Warp 等技术公司在将其核心代码转为开源时会选择 AGPL。这被用作一种战略性手段：既能吸引外部开发者的贡献，又能防止其他公司未经许可获取该源代码并将其重新加工成封闭的商业 Cloud 服务，从而获取垄断利益。
