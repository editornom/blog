# 什么是 SD-WAN？

## 词典定义 (Dictionary Definition)
SD-WAN 是软件定义广域网（Software-Defined Wide Area Network）的缩写，是一种通过软件控制和管理广域网（WAN）的虚拟网络架构。它利用集中式控制功能实现智能流量管理，与传统以硬件为中心的网络不同，该技术通过优化路径选择和灵活的带宽管理来提升网络性能并降低成本。

## 实务应用案例 (Practical Use Case)
在全球拥有多个分支机构的跨国企业通常会引入 SD-WAN 以降低高昂的专线（MPLS）费用。通过整合普通宽带互联网线路与现有专线，并为视频会议或基于 Cloud 的协作工具等关键流量优先分配稳定路径，从而实现办公效率的最大化。

## 相关词汇 (Related Words)
* SASE (Secure Access Service Edge)
* WAN (Wide Area Network)
* MPLS (Multi-Protocol Label Switching)
