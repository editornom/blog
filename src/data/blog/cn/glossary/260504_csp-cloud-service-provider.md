# 什么是 CSP？

**词典定义 (Dictionary Definition)**
云服务提供商 (Cloud Service Provider, CSP) 是指通过互联网提供服务器、存储、数据库、网络等虚拟化计算资源的按需 (On-demand) 服务企业。用户无需直接拥有或管理物理基础设施，而是租赁 CSP 构建的资源，并遵循按需付费的计量计费模式。代表性供应商包括亚马逊网络服务 (AWS)、微软 Azure (Azure) 和谷歌云平台 (GCP)。

**实际应用案例 (Practical Use Case)**
为防止对特定 CSP 的技术供应商锁定 (Vendor Lock-in) 现象并最大化服务可用性，企业通常会选择多个 CSP 分散部署基础设施，采用多云 (Multi-Cloud) 策略。

**相关术语 (Related Words)**
* 多云 (Multi-Cloud)
* 供应商锁定 (Vendor Lock-in)
* 云安全 (Cloud Security)
