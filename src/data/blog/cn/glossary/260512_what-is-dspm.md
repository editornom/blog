# 什么是 DSPM？

### 词典定义 (Dictionary Definition)
DSPM (Data Security Posture Management，数据安全态势管理) 是一种安全框架，旨在识别分布在整个 Cloud 环境中的数据位置，对该数据的敏感度和重要性进行分类，并持续监控安全漏洞及访问权限。它超越了探测基础设施配置错误的传统方式，重点在于确保数据本身的生命周期和可见性。

### 实际应用场景 (Practical Use Case)
安全负责人可以利用 DSPM 自动识别散布在组织 Cloud 存储中、未受管理且处于闲置状态的客户个人身份信息 (PII) 或企业机密数据（即“影子数据/Shadow Data”），并预先探测及处置因权限设置不当而可能导致的外部泄露风险。

### 相关词汇 (Related Words)
* CSPM (Cloud Security Posture Management)
* CNAPP (Cloud Native Application Protection Platform)
* DLP (Data Loss Prevention)
