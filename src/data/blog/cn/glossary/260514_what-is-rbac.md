# 什么是 RBAC？

## 词典定义 (Dictionary Definition)
基于角色的访问控制 (Role-Based Access Control, RBAC) 是一种根据用户在组织内担任的“角色 (Role)”而非个人身份来管理系统资源访问权限的方法。该模型通过预先定义每个角色所需的最小权限集，并将用户分配到相应的角色中，从而降低了安全管理的复杂性并有效防止权限滥用。

## 实际应用案例 (Practical Use Case)
在基于 Agentic AI 的遗留系统现代化架构中，RBAC 常被用作一种治理手段。例如，通过为 AI Agent 授予“数据查询者”角色，限制其仅能调用只读 API。这样可以有效控制自主型 Agent 意外更改系统设置或删除数据的风险，确保系统运行的安全稳健。

## 相关术语 (Related Words)
- ABAC (Attribute-Based Access Control)
- ACL (Access Control List)
- IAM (Identity and Access Management)
