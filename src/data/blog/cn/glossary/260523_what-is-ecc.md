# 什么是 ECC (Elliptic Curve Cryptography)？

### 词典定义 (Dictionary Definition)
椭圆曲线密码学 (ECC) 是一种基于椭圆曲线理论的公开密钥加密方式。它利用椭圆曲线离散对数问题的数学难题来进行数据加密和数字签名。其特点是，在提供相同安全级别的情况下，与 RSA 等传统非对称加密方式相比，使用的密钥长度要短得多。因此，它的运算速度更快，内存和功耗更低，在资源受限的环境中表现非常高效。

### 实际应用案例 (Practical Use Case)
- **网络安全 (SSL/TLS)**: 广泛应用于现代浏览器与服务器之间的安全通信，作为证书签名和密钥交换算法。
- **移动及 IoT 设备**: 在计算能力有限的智能手机或物联网 (IoT) 设备中，是实现低功耗、高安全性加密的首选方案。
- **区块链技术**: 在比特币 (Bitcoin) 和以太坊 (Ethereum) 等加密货币中，被采纳为验证交易合法性的数字签名算法 (ECDSA)。
