# 什么是 SASE？

### 词典定义 (Dictionary Definition)
SASE（Secure Access Service Edge，安全访问服务边缘）是一种将网络功能 SD-WAN（软件定义广域网）与多种安全功能集成并作为 Cloud 服务提供的架构模型。它摆脱了传统的以物理数据中心为核心的网络安全模式，其核心思想是在云边缘（Cloud Edge）无论用户或设备的位置如何，都能实施统一的安全策略并控制网络路径。该框架旨在确保可见性、解决管理的复杂性，并以云原生（Cloud Native）方式运行网络和安全基础设施。

### 实际应用案例 (Practical Use Case)
在远程办公和 Cloud 转型加速的企业环境中，当分散的分支机构或个人用户访问公司内部网络及外部云应用程序时，即可使用该架构。通过将所有流量集中到服务提供商的数据中心（PoP，存在点）并应用统一的安全策略，企业既能维持安全治理，又能提高运营效率（相比专用线路）。特别是在对延迟（Latency）敏感的环境（如智能工厂）中，常通过结合主权混合治理（Sovereign Hybrid Governance）来确保运营稳定性。
