- q: "什么是公开密钥加密？"
  a: "这是一种使用公钥和私钥这对不同密钥进行数据加密和解密的方式。它克服了对称加密必须提前共享密钥的物理局限性，成为了现代数字安全的标准。"
- q: "公开密钥加密最大的优点是什么？"
  a: "最大的成果是解决了‘密钥分发问题’。任何人都可以持有用于加密信息的公钥，而只有本人持有用于解密的私钥，这使得在互联网这种开放环境下进行安全通信成为可能。"
- q: "为什么说这种方式是‘数学赌博’？"
  a: "因为公开密钥系统依赖于‘质因数分解或离散对数问题在现有计算资源下难以解决’的假设。也就是说，安全性并未得到完美的数学证明，只是目前尚未发现高效的解法，这包含了一种不确定性。"
- q: "RSA 和 ECC 有什么区别？"
  a: "RSA 利用了大整数质因数分解的难题，而 ECC 利用了椭圆曲线上的离散对数问题。ECC 可以用比 RSA 少得多的比特数提供同等的安全强度，因此在运算效率方面被认为是更先进的技术。"
- q: "为什么说公开密钥加密的运算效率较低？"
  a: "因为它需要执行复杂的数学模幂运算或点加运算。与执行简单比特置换的对称加密方式相比，它消耗的 CPU 资源要多出数百到数千倍，数据处理速度也明显慢得多。"
- q: "为什么公开密钥加密中必须使用填充（Padding）技术？"
  a: "如果只使用原始算法，相同的明文总是会输出相同的密文，攻击者据此可以推测内容。像 OAEP 这样的填充技术通过在明文中混入随机数据来隐藏密文模式，起到增强安全性的作用。"
- q: "混合加密系统是指什么样的结构？"
  a: "这是一种结合了公开密钥的安全性和对称密钥的高效性的方式。沉重的公开密钥仅用于安全地将对称密钥传递给对方，而实际的大容量数据加密传输则由速度较快的对称密钥负责，这是一种畸形但实用的结构。"
- q: "量子计算对公开密钥加密构成了什么威胁？"
  a: "搭载 Shor 算法的量子计算机可以瞬间解决质因数分解和离散对数问题。这将从根本上瓦解现有的 RSA 和 ECC 体系，这也是迫切需要向后量子加密（PQC）进行世代交替的原因。"
- q: "使用公开密钥方式会因为服务器负载增加而导致成本上升吗？"
  a: "是的，没错。像 RSA 这样的公开密钥运算非常消耗 CPU 资源。因此，我们不会用公开密钥处理所有数据，而是采用混合方式，仅在初始连接时用于交换密钥，从而优化服务器成本和速度。"
- q: "听说最近椭圆曲线加密比 RSA 更好，是真的吗？"
  a: "是的，确实如此。椭圆曲线加密（ECC）使用的密钥比 RSA 短得多，但安全性却更强。由于密钥小，数据传输量也随之减少，运算相对更快，因此现在的智能手机 App 或浏览器安全大多首选 ECC。"

<div class="bluf"><strong>[BLUF]</strong><p>公开密钥加密是解决对称密钥分发问题的伟大妥协，但其本质上是一个依赖于未经证明的数学难题和极低运算效率的不稳定架构。如果没有填充（Padding）和混合结构，它就是一个无法自立的“臃肿堡垒”。随着量子计算的出现，它被定义为必将被后公开密钥时代所取代的历史遗产。</p></div>

在支撑现代社会的所有数字信任背后，都潜伏着一个名为“数学难题”的摇摇欲坠的假设。从我们每天使用的银行系统到私密的即时通讯对话，守护这些安全性的公开密钥加密技术，其实是人类在拥有崇高地位的同时，也选择了沉重且低效结构的“巨大妥协”产物。

## 1. 信任的起源：解决对称密钥分发难题的“巨大妥协”

 ### - 共享秘密的局限与迪菲-赫尔曼开启的非对称时代

 过去的加密体系依赖于对称密钥方式，即通信双方必须预先共享密钥才能工作。然而，在互联网这样一个广阔且开放的环境中，与全球不特定的多数人安全地分享密钥，在物理上几乎是不可能的。为了突破这一局限，<a href="/cn/glossary/trapdoor-function" class="glossary-tooltip" data-definition="一种在一个方向上容易计算，但在反方向上如果没有特定信息就无法计算的函数">陷门函数</a>的概念具有革命性。任何人都可以锁定信息，但只有持有钥匙的主人才能打开它，这种非对称逻辑开启了安全的新时代。

 然而，这种创新并非没有代价。虽然不再需要通信双方之间的预先信任，但我们开始支付运算低效这一巨大成本。这也是人类历史上为了安全而放弃速度，选择复杂性而非灵活性的一种选择。

 ### - 未经证明的数学难题：质因数分解与离散对数的“赌博”

 你是否知道，我们绝对信任的 RSA 或 ECC 等加密体系，其实是基于“尚未解决的作业”？这些系统依赖于一种经验统计，即质因数分解的难度或离散对数问题的复杂性在未来也不会改变。也就是说，从严格意义上讲，这并不是经过数学完美证明的安全，而是建立在“目前的计算资源难以破解”这一假设之上的巨大赌博。

## 2. 效率的悖论：为什么我们要给 64 位传输披上 2048 位的铠甲？

 ### - RSA 的致命弱点：运算负载与低效的密文膨胀（Ciphertext Expansion）

 在实际的数据传输过程中，公开密钥加密表现出了极低的效率。RSA 加密的核心——<a href="/cn/glossary/modular-exponentiation" class="glossary-tooltip" data-definition="求幂结果对特定数取模的运算，是 RSA 加密的核心数学基础">模幂运算</a>，与执行简单比特置换的对称加密（AES）相比，是消耗 CPU 资源多出数百到数千倍的罪魁祸首。为了保护仅仅几个字节的信息而生成 2048 位的巨大密文块，这种低效无异于为了移动一根针而动用庞大的装甲车。

 ### - ECC（椭圆曲线）的出现证明了 RSA 的臃肿及依然存在的运算局限

 为了解决 RSA 的臃肿，椭圆曲线加密（ECC）出现了，并显著减小了密钥尺寸。但 ECC 同样需要经过点加运算等复杂的数学程序，在实时加密大容量数据方面，结构性局限依然明显。最终，我们并不是通过公开密钥获得了“效率”，而仅仅是实现了“信任的传递”。

| 加密方式 | 主要数学原理 | 对应安全强度的密钥长度 (bits) | 运算速度 (对比 AES-128) |
| :--- | :--- | :--- | :--- |
| RSA-3072 | 质因数分解难题 | 3,072 bits | 慢约 1,000 倍以上 |
| ECC-256 | 椭圆曲线离散对数 | 256 bits | 慢约 100 倍以上 |
| AES-128 | 替代与置换运算 | 128 bits | 基准 (极快) |

## 3. 天生脆弱性与“呼吸机”：填充（Padding）与对称密钥的阴影

 ### - 原始加密在选择明文攻击（Chosen-Plaintext Attack）面前的无力感

 作为纯粹数学算法的公开密钥加密，其实比想象中要脆弱得多。由于相同的明文总是输出相同的密文，它在攻击者尝试代入可预测明文的“猜测”面前非常无力。为了防御这一点，我们增加了名为 OAEP 等填充（Padding）技术的辅助装置。这直观地说明了原始加密技术无法自我保护，必须依赖外部辅助装置。

 ### - 混合加密系统：运送“赛车”的“笨重装甲车”

> 公开密钥加密并不是独立的完美安全对策，它仅仅是为了安全运送名为“对称密钥”的赛车而设计的笨重装甲车。

 现代安全系统拥有一种畸形的共生结构：公开密钥负责安全传递对称密钥，而实际数据的快速处理则由对称密钥承担。我们想要使用速度快的“赛车”，但为了穿过密钥传递这条危险的道路，不得不雇佣沉重的“装甲车”。这种双重结构可以看作是现代 IT 生态系统为了维持安全而支付的一种“必要之恶”维护费。

## 4. 倒塌堡垒的终局：量子计算与后公开密钥的序幕

 ### - <a href="/cn/glossary/shors-algorithm" class="glossary-tooltip" data-definition="一种可以使用量子计算机极快地解决质因数分解和离散对数问题的算法，能够瓦解现有的 RSA 或 ECC 等公开密钥加密体系。">Shor 算法</a>瞄准了非对称加密的心脏

 守护了堡垒数十年的数学屏障，现在正因量子计算这一巨浪而动摇。Shor 算法的出现精准地瞄准了质因数分解和离散对数问题这两个公开密钥的心脏。如果性能充足的量子计算机出现，我们目前使用的 RSA 和 ECC 体系将瞬间瓦解，其寿命已进入倒计时。

 ### - 从巨大波澜的终点审视公开密钥加密的里程碑价值与局限

 公开密钥加密所具有的数值局限非常明确：
 1. 运算效率：RSA-2048 的模幂运算在软件实现时，比没有硬件加速的 AES-128 多消耗约 1,000~10,000 倍的 CPU 周期。
 2. 数据膨胀：在 RSA 加密中，即使发送 1 字节的数据，也会生成至少 256 字节（2048 位）的密文块，导致带宽浪费。
 3. 量子威胁：在使用 Shor 算法时，现有的 RSA 和 ECC 体系在拥有足够量子比特的量子计算机面前，具有在多项式时间（Polynomial Time）内被破解的结构性脆弱性。

# 结论：建立在不完整数学之上的现代安全历史遗产

 我们所享受的数字信任基础，就像是建立在“难以解决”这一数学推测之上的、随时可能崩塌的巨大赌场。尽管公开密钥加密是一个低效且不稳定的架构，但不可否认的是，它是人类为了克服通信环境根本局限而创造出的最精妙的历史遗产。现在，我们正站在超越这座臃肿堡垒、准备迎接符合量子时代的新安全愿景的时刻。
