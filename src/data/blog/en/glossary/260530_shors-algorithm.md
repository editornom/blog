# What is Shor's Algorithm?

### Dictionary Definition
Shor's algorithm is a quantum algorithm formulated by Peter Shor in 1994. it is a numerical analysis technique capable of solving the prime factorization problem of massive integers overwhelmingly faster than any classical computer. While classical algorithms consume exponential time for factorization, Shor's algorithm can complete these calculations within polynomial time, marking a revolutionary turning point in computational complexity theory.

### Practical Use Case
Shor's algorithm serves as the primary evidence proving the vulnerability of the RSA algorithm—the bedrock of modern Public Key Infrastructure (PKI)—and Elliptic Curve Cryptography (ECC), which is based on discrete logarithm problems. It suggests that if large-scale quantum computers are realized, current digital security frameworks could be rendered obsolete. Consequently, in security practice and research, it is used as a benchmark for designing and standardizing Post-Quantum Cryptography (PQC) technologies that can withstand quantum-based attacks.
