# What is a CSP?

**Definition**
A Cloud Service Provider (CSP) is an entity that provides virtualized computing resources—such as servers, storage, databases, and networking—over the internet on an on-demand basis. Rather than owning or managing physical infrastructure directly, users rent the resources built by the CSP and follow a pay-as-you-go pricing model, paying only for what they consume. Leading examples of such providers include Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

**Practical Application**
To avoid technical Vendor Lock-in and maximize service availability, many enterprises adopt a multi-cloud strategy, distributing their infrastructure across multiple CSPs rather than relying on a single provider.
