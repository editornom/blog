# What is a Context Window?

### Dictionary Definition
A context window refers to the maximum range of data that an AI model can simultaneously process and understand during a single inference cycle. Its size is determined by the number of tokens (the fundamental units of text), acting as an indicator of the model's 'working memory' capacity—specifically, how much conversational context or input information the model can reference at once.

### Practical Use Case
In professional environments, the context window is critical when inputting hundreds of pages of legal contracts or technical documentation to generate a comprehensive summary. It is also essential for uploading the entire source code of a complex software project to analyze inter-system dependencies and identify bugs across the whole codebase.
