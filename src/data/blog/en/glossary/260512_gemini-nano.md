# What is Gemini Nano?

### Dictionary Definition
Gemini Nano is the smallest and most efficient member of Google’s Gemini large language model (LLM) family, specifically optimized for on-device execution. It is designed to run locally on consumer hardware—such as mobile chipsets (APs) and personal computers (CPUs, GPUs, and NPUs)—delivering high-performance, low-power natural language processing, text summarizing, smart reply, and proofreading features without needing an active internet connection.

### Practical Use Case
In smartphones (such as Google Pixel devices), it is used to transcribe and summarize recorded voice notes in real-time. In desktop browsers (such as Google Chrome), it powers 'Help me write,' automated tab categorization, and conversational history search. All processing occurs locally within a secure sandbox, meaning not a single byte of personal user data is ever uploaded to a cloud server.
