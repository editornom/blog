# What is RBAC?

## Dictionary Definition
Role-Based Access Control (RBAC) is a method of managing access permissions to system resources based on an individual's assigned 'role' within an organization, rather than their specific user ID. It is a security model designed to reduce management complexity and prevent the abuse of privileges by predefining the minimum set of permissions required for each role and assigning users accordingly.

## Practical Use Case
In Agentic AI-based legacy modernization architectures, RBAC serves as a critical governance mechanism to mitigate operational risks. By assigning a 'Data Viewer' role to an AI agent—restricting it to read-only API calls—organizations can prevent autonomous agents from inadvertently modifying system configurations or deleting critical data.

## Related Terms

- ACL (Access Control List)
