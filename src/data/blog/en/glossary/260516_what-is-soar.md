# What is SOAR?

### Dictionary Definition
SOAR (Security Orchestration, Automation and Response) refers to software solutions and frameworks that combine security orchestration, automation, and incident response technologies to streamline security operations. First defined by Gartner, this concept focuses on integrating various security tools and technologies into a single platform to collect threat data. By automatically analyzing and handling repetitive security incidents according to predefined procedures (Playbooks), it minimizes manual intervention by security personnel and significantly increases the speed of response.

### Practical Use Case
In a large-scale enterprise environment, a SOAR platform receives thousands of threat alerts detected by SIEM (Security Information and Event Management) solutions. Following predefined playbooks, the system prioritizes the severity of threats, automatically blocks malicious IPs, and immediately delivers a report containing detailed information to analysts, drastically reducing the overall incident response time.
