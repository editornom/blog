# What is DSPM?

### Dictionary Definition
Data Security Posture Management (DSPM) is a security framework designed to discover the location of distributed data across cloud environments, classify its sensitivity and importance, and continuously monitor for security vulnerabilities and access permissions. It goes beyond traditional methods of detecting infrastructure misconfigurations to focus on securing the data itself and ensuring visibility throughout its entire lifecycle.

### Practical Use Case
Security professionals use DSPM to automatically identify 'Shadow Data'—unmanaged or forgotten Personally Identifiable Information (PII) or corporate secrets residing within cloud storage. It enables organizations to proactively detect and remediate risks, such as potential data leaks caused by improper permission settings or unauthorized access.
