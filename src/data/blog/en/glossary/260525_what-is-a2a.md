### Dictionary Definition
A2A (Agent-to-Agent) refers to a direct communication and collaboration structure between intelligent agents. It is a core interaction model within Multi-Agent Systems (MAS) that enables distributed AI agents to exchange information via predefined protocols or APIs, leveraging each other's capabilities to complete complex tasks that a single agent would struggle to solve. This encompasses workflows where individual agents autonomously invoke functions and exchange data with other agents in an agent-centric infrastructure.

### Practical Use Case
In an enterprise business automation environment, A2A is utilized in sequential automation processes. For example, a research agent collects raw data and transmits it to an analysis agent. The analysis agent then processes this data and sends it to a report generation agent, which ultimately produces the final deliverable.
