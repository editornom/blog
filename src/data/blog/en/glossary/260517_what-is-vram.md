# What is VRAM?

### Dictionary Definition
VRAM (Video Random Access Memory) is dedicated high-speed memory used by a Graphics Processing Unit (GPU) to process image rendering and computational data. In the modern AI ecosystem, it serves as a critical physical resource for loading model weights and operational data, acting as a decisive factor in determining the scale and operational environment of AI models.

### Practical Use Case
By adopting Small Language Models (SLM), VRAM occupancy is reduced, making it easier to establish On-device AI environments where AI services can run directly on consumer-grade PCs or mobile devices.
