# What is L7?

### Dictionary Definition
L7 refers to the Application Layer, the highest level of the OSI (Open Systems Interconnection) 7-layer model. It enables users to interact with network applications, and high-level protocols tailored to specific service purposes—such as HTTP, HTTPS, DNS, FTP, and SMTP—operate at this layer. In terms of network management and security, it represents a technical unit that identifies the actual data (payload) within packets, going beyond simple IP addresses or port numbers to control or analyze traffic.

### Practical Use Case
Cloud-native observability tools leveraging eBPF technology intercept and analyze L7 protocol data at the kernel level. This allows for the real-time monitoring of HTTP call success rates and response latency between microservices without requiring any code modifications.
