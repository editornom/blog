# What is SD-WAN?

## Dictionary Definition
Standing for Software-Defined Wide Area Network, SD-WAN is a virtual network architecture that controls and manages a Wide Area Network (WAN) using software. It intelligently manages traffic via centralized control functions, and unlike traditional hardware-centric networks, it enhances network performance and reduces costs through optimal path selection and flexible bandwidth management.

## Practical Use Case
Multinational corporations with multiple global branches adopt SD-WAN to reduce expensive leased line (MPLS) costs. By integrating standard broadband internet lines with existing leased lines, it maximizes operational efficiency by prioritizing stable paths for critical traffic such as video conferencing or cloud-based business tools.
