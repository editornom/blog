# What is Knowledge Distillation?

### Dictionary Definition
Knowledge Distillation is a machine learning technique designed to transfer knowledge from a large, sophisticated artificial intelligence model (Teacher Model) to a relatively smaller and more efficient one (Student Model). By utilizing "soft targets"—the output probabilities of the complex teacher model—as training data, the student model is trained to mimic the teacher's inference logic. This process aims to minimize performance loss while significantly reducing the model size and enhancing inference speed.

### Practical Use Case
In architectures like Andrej Karpathy's 'LLM Wiki,' this technique is used to refine and accumulate sophisticated outputs generated by high-cost inference models into structured knowledge in Markdown format. This approach allows organizations to "assetize" knowledge obtained from a single high-cost inference, enabling lightweight models to provide immediate, low-cost responses to similar requests in the future, thereby optimizing resource efficiency.
