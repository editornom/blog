# What is AGPL?

### Dictionary Definition
The AGPL (GNU Affero General Public License) is a strong copyleft license released by the Free Software Foundation (FSF). It was specifically designed to address the 'ASP Loophole' found in the original GPL license. Under the GPL, the obligation to disclose source code only triggers upon physical distribution of the software. This allowed entities to run modified code as a network service (SaaS) without being required to share their source code. The AGPL closes this loophole: if you modify AGPL-licensed software and provide services over a network, you are obligated to make the source code of that modified version available to the users.

### Practical Use Case
Tech companies, such as the terminal tool developer Warp, often choose AGPL when transitioning their core code to open source. This serves as a strategic mechanism to encourage external contributions while preventing other companies from taking the source code and repackaging it into a closed, proprietary cloud service to gain exclusive profits without contributing back to the project.
