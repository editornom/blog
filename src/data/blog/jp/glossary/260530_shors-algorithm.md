# ショアのアルゴリズムとは？

### 辞書的定義 (Dictionary Definition)
ショアのアルゴリズムは、1994年にピーター・ショア（Peter Shor）によって考案された量子アルゴリズムで、巨大な整数の素因数分解問題を古典コンピュータよりも圧倒的に速く解決できる数値解析手法です。古典コンピュータのアルゴリズムが素因数分解に指数時間（Exponential time）を要するのに対し、ショアのアルゴリズムは多項式時間（Polynomial time）内に演算を完了できるため、計算複雑性理論における画期的な転換点と評価されています。

### 実務使用例 (Practical Use Case)
ショアのアルゴリズムは、現代の公開鍵暗号体系（PKI）の根幹であるRSAアルゴリズムや、離散対数問題に基づく楕円曲線暗号（ECC）の脆弱性を立証する核心的な根拠として活用されています。大規模な量子コンピュータが実現した場合、現在のデジタルセキュリティ体系が無効化される可能性を示唆しており、これに伴いセキュリティの実務および研究分野では、ショアのアルゴリズムの攻撃を防ぐことができる耐量子計算機暗号（PQC）技術を設計し、標準化するための基準点とされています。
