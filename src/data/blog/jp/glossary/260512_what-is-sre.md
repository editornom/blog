# SRE（サイト信頼性エンジニアリング）とは？

## 辞書的定義 (Dictionary Definition)
SRE（Site Reliability Engineering、サイト信頼性エンジニアリング）は、Googleによって提唱されたシステム運用の手法であり、ソフトウェア工学的なアプローチをITインフラおよび運用の課題に適用する実務体系を指します。システムの信頼性、可用性、効率性を確保するために自動化とモニタリングを積極的に活用し、手作業（トイル、Toil）を最小限に抑え、サービスレベル目標（SLO）に基づいてシステムの安定性を定量的に管理するのが特徴です。

## 実務での活用事例 (Practical Use Case)
eBPFのようなセキュリティ技術を導入する過程において、SREはセキュリティロジックがシステム可用性に与える負荷を測定し、モニタリング体制を構築します。もしセキュリティプログラムのデプロイ後にシステムコールの処理速度が低下し、あらかじめ設定されたエラー予算（Error Budget）を超過するリスクが検知された場合、SREは可用性を確保するためにデプロイを中断するか、パフォーマンス最適化作業を優先的に行うよう意思決定を下します。

## 関連用語 (Related Words)
* **DevOps**: ソフトウェアの開発と運用の連携を強調する文化的哲学であり、SREはこれを具体的な工学的手法で実現したモデルであると評価されています。
* **SLO (Service Level Objective)**: サービス提供者が遵守しようとするパフォーマンスおよび可用性に関する具体的な目標値です。
* **Error Budget (エラー予算)**: SLOを達成するために許容可能なシステム停止時間の総量を指し、新しい機能のデプロイ可否を判断する基準となります。
