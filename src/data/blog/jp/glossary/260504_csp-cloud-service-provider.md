# CSPとは？

**定義 (Definition)**
クラウドサービスプロバイダー（Cloud Service Provider, CSP）とは、インターネットネットワークを通じて、サーバー、ストレージ、データベース、ネットワークなどの仮想化されたコンピューティングリソースをオンデマンド（On-demand）形式で提供する企業を指します。ユーザーは物理的なインフラを直接所有したり管理したりする必要がなく、CSPが構築したリソースをレンタルして使用し、使用した分だけ料金を支払う従量課金制モデルに従います。代表的な提供業者としては、Amazon Web Services（AWS）、Microsoft Azure（Azure）、Google Cloud Platform（GCP）などがあります。

**実務での活用例 (Practical Use Case)**
企業は、特定のCSPに対する技術的依存（Vendor Lock-in、ベンダーロックイン）を防止し、サービスの可用性を最大化するために、複数のCSPを選定してインフラを分散配置するマルチクラウド戦略を採用しています。

**関連用語 (Related Words)**
* マルチクラウド (Multi-Cloud)
* ベンダーロックイン (Vendor Lock-in)
* クラウドセキュリティ (Cloud Security)
