# L7とは？

### 辞書的定義 (Dictionary Definition)
L7は、OSI（Open Systems Interconnection）参照モデルの最上位レイヤーであるアプリケーション層（Application Layer）を指します。ユーザーがネットワークアプリケーションと相互作用できるように支援し、HTTP、HTTPS、DNS、FTP、SMTPなど、サービスの目的に応じた高次プロトコルがこのレイヤーで動作します。ネットワーク管理やセキュリティの側面では、単なるIPアドレスやポート番号を超え、パケット内部の実際のデータ（ペイロード）を識別してトラフィックを制御・分析する技術的な単位を意味します。

### 実務での活用事例 (Practical Use Case)
eBPF技術を活用した Cloud ネイティブな観測性ツールでは、カーネルレベルでL7プロトコルデータを傍受して分析することで、個別のコード修正を行うことなく、マイクロサービス間のHTTP呼び出し成功率や応答遅延時間をリアルタイムにモニタリングするために使用されます。
