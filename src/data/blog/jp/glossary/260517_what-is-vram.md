# VRAMとは？

### 辞書的な定義 (Dictionary Definition)
VRAM（Video Random Access Memory）は、グラフィックス処理装置（GPU）において画像レンダリングおよび演算データを処理するために使用される専用の高速メモリです。現代の人工知能エコシステムでは、モデルの重み（Weight）や演算データをロードする核心的な物理リソースとして活用され、AIモデルの規模や駆動環境を決定する決定的な要素となります。

### 実務での使用例 (Practical Use Case)
小型言語モデル（SLM）を導入すると、VRAMの占有率が下がり、一般ユーザー用PCやモバイルデバイスでもAIサービスを直接駆動できるオンデバイス環境を構築しやすくなります。
