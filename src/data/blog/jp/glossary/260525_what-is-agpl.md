# AGPLとは？

### 辞書的定義 (Dictionary Definition)
AGPL（GNU Affero General Public License）は、フリーソフトウェア財団（FSF）が公開した強力なコピーレフト（Copyleft）ライセンスです。従来のGPLライセンスが、ソフトウェアを物理的に配布する場合にのみソースコードの公開義務が発生するという点を利用し、ネットワークサービス（SaaS）の形態でコードを実行する場合にはソースコードを公開しなくてもよかった、いわゆる「ASPループホール（ASP Loophole）」を解決するために設計されました。AGPLライセンスが適用されたソフトウェアを修正し、ネットワークを通じてリモートでサービスを提供する場合、ユーザーはその修正版のソースコードを公開する義務を負います。

### 実務での使用例 (Practical Use Case)
ターミナルツールであるWarpのような技術企業が、自社のコアコードをオープンソースに転換する際にAGPLを選択します。これは、外部の開発者からの貢献を促しながらも、他企業がそのソースコードを無断で持ち出し、閉鎖的な商用 Cloud サービスとして再加工して独占的利益を得ることを防ぐための戦略的な仕組みとして活用されています。
