# EUVとは？

### 辞書的定義 (Dictionary Definition)
EUV（Extreme Ultraviolet、極端紫外線）は、半導体露光（Lithography）工程において、シリコンウェハーに回路パターンを描くために使用される、波長13.5nmの光源です。従来の工程で使用されていたフッ化アルゴン（ArF）光源と比較して、波長の長さが約14分の1と短いため、7ナノメートル（nm）以下の超微細な回路パターンを実現するために不可欠な次世代技術です。

### 実務での活用事例 (Practical Use Case)
グローバルなファウンドリ企業は、5nmや2nm工程などの超微細な半導体量産のために、EUV露光装置を導入しています。これにより、回路の線幅を狭めてチップの集積度を高め、電力効率と演算能力を最大化した高性能プロセッサの生産が可能となります。
