# DSPMとは？

### 辞書的定義 (Dictionary Definition)
DSPM（Data Security Posture Management、データセキュリティ態勢管理）は、クラウド環境全体に分散されたデータの位置を把握し、そのデータの機密性と重要度を分類した上で、セキュリティの脆弱性やアクセス権限を継続的に監視するセキュリティフレームワークです。これは、インフラの設定ミスを検知する従来のアプローチから一歩進み、データ自体のライフサイクルと可視性の確保に重点を置いています。

### 実務での活用事例 (Practical Use Case)
セキュリティ担当者が、組織内のクラウドストレージに散在し、管理されずに放置されている顧客の個人情報（PII）や企業の機密データ、いわゆる「シャドーデータ（Shadow Data）」を自動的に識別する際に活用されます。また、不適切な権限設定によって外部へ流出する恐れのあるリスクを事前に検知し、適切な対策を講じるプロセスにおいても重要な役割を果たします。

### 関連用語 (Related Words)
