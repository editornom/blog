# URLLCとは？

### 辞書的定義 (Dictionary Definition)
URLLC（Ultra-Reliable Low-Latency Communications、超高信頼低遅延通信）は、5G移動通信の3大核心サービス分野の一つで、極めて低い遅延時間と高いデータ転送の信頼性を保証する技術規格です。通常、1ms以下の遅延時間と99.999%以上の転送成功率を目標としており、リアルタイム処理が不可欠なミッションクリティカル（Mission-Critical）な産業サービスの安定性を確保するための核心的な基盤技術です。

### 実務での使用例 (Practical Use Case)
スマートファクトリーの精密ロボット制御システムや、自動運転車のV2X（Vehicle-to-Everything）通信環境の構築に活用されます。また、遠隔手術やドローン制御のように、わずか1秒の遅延や接続エラーが致命的な事故につながる可能性のある高リスクなビジネス現場で採用されています。実際の運用環境においてURLLCの性能を完全に保証するためには、5G SA（Standalone）インフラベースのネットワークスライシングを通じたエンドツーエンド（End-to-End）のリソース隔離が伴う必要があります。

### 関連用語 (Related Words)
5G SA（Standalone）、ネットワークスライシング（Network Slicing）、eMBB（高速大容量通信）
