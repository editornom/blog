# SD-WANとは？

## 辞書的な定義 (Dictionary Definition)
ソフトウェア定義広域ネットワーク（Software-Defined Wide Area Network）の略称で、ソフトウェアを介して広域ネットワーク（WAN）を制御・管理する仮想ネットワークアーキテクチャです。中央集中型の制御機能によりトラフィックをインテリジェントに管理し、従来のハードウェア中心のネットワークとは異なり、最適な経路選択と柔軟な帯域幅管理を通じて、ネットワークパフォーマンスの向上とコスト削減を実現する技術です。

## 実務での使用例 (Practical Use Case)
世界各地に複数の拠点を構える多国籍企業が、高額な専用線（MPLS）のコストを削減するために導入します。一般的なブロードバンド回線と既存の専用線を統合して運用しながら、ビデオ会議やCloudベースの業務ツールといった重要なトラフィックに対して安定した経路を優先的に割り当てることで、業務効率を最大化するために活用されます。

## 関連用語 (Related Words)

* WAN (Wide Area Network)
* MPLS (Multi-Protocol Label Switching)
