# GIGO（Garbage In, Garbage Out）とは？

### 辞書的定義 (Dictionary Definition)
GIGOは「Garbage In, Garbage Out」の略称で、システムに不良な、あるいは無意味なデータを入力すれば、その結果もまた不良、あるいは無意味なものになるという、コンピュータサイエンスおよび情報通信技術分野の格言です。これは、アウトプットの品質が処理プロセスだけでなく、入力される基礎データの質によって決定されるという原理を内包しています。

### 実務における活用事例 (Practical Use Case)
人工知能（AI）業界において、Transformer（トランスフォーマー）アーキテクチャのように高度に設計されたアルゴリズムを使用したとしても、学習データの精製レベルが低ければ、モデルの性能が低下する現象が発生します。特に大規模言語モデル（LLM）の商用化プロセスにおいて、モデルが高度化するほど低質なデータに敏感に反応し、信頼できない結果を導き出す「GIGOの進化」現象が確認されており、これを解決するためのデータガバナンスの重要性が強調されています。

### 関連用語 (Related Words)
- **データガバナンス (Data Governance)**: データの品質とセキュリティを維持するための管理体系です。
- **Transformer (トランスフォーマー)**: 並列処理に最適化された現代のAIにおける中核的なアルゴリズムアーキテクチャです。
- **データコンテキスト (Data Context)**: データが持つ文脈的な成熟度と価値を意味します。
