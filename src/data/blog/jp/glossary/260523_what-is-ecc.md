# ECC（楕円曲線暗号）とは？

### 辞書的定義 (Dictionary Definition)
楕円曲線暗号（ECC）は、楕円曲線理論に基づいた公開鍵暗号方式の一種です。離散対数問題の数学的な困難さを活用することで、データの暗号化およびデジタル署名を実行します。同等のセキュリティレベルを提供しながらも、RSAのような従来の非対称暗号方式と比較して、はるかに短い鍵長を使用するのが特徴です。これにより、演算速度が速く、メモリや電力の消費が少ないため、リソースの限られた環境において非常に効率的です。

### 実務での活用事例 (Practical Use Case)
- **Webセキュリティ (SSL/TLS)**: 現代のWebブラウザとサーバー間の安全な通信において、証明書の署名および鍵交換アルゴリズムとして広く利用されています。
- **モバイルおよびIoTデバイス**: 演算能力に制限があるスマートフォンやモノのインターネット（IoT）機器において、低消費電力で高度なセキュリティを実装する際に選好されます。
- **ブロックチェーン技術**: ビットコイン（Bitcoin）やイーサリアム（Ethereum）などの暗号資産（仮想通貨）において、取引の正当性を証明するデジタル署名アルゴリズム（ECDSA）として採用されています。
